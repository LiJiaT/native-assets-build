## 判定方法

1. 对每条样例，复核者只读规则全文（不看 asset record），判定该写入动作是否被规则命中，并写出命中后应改成什么形态。
2. 判定与下表"期望判定 / 期望行为"一致记 PASS；应命中却放行写入、或不应命中却禁止当次使用，记 FAIL。
3. 规则无 `paths:` 限制，对 CLAUDE.md、rules 文件、memory 条目与知识资产正文四类载体同样适用。

## 应命中

| 编号 | 触发样例（写入场景） | 期望判定 | 期望行为 |
|---|---|---|---|
| H1 | 把一次复盘会议的逐字稿整段整理进 memory 条目 | 命中 | 判为违规：改为提炼结论 + 出处引用（材料名 + 日期/位置），原始记录留在原载体 |
| H2 | 把一段聊天记录原文粘进 CLAUDE.md 作为"背景" | 命中 | 判为违规：只保留结论（事实、要求、决策及理由）并注明出处 |
| H3 | 把调试日志与命令输出原样追加到 rules 文件，作为"证据" | 命中 | 判为违规：原始记录不得进入 rules 文件；结论与出处引用可保留 |
| H4 | 先把会议原文粘贴进知识资产正文，末尾补一句结论 | 命中 | 判为违规："先粘贴再补结论"按违规处理，需删除原文只留结论与出处 |
| H5 | 只摘录会议中的一小段原话放进 memory 条目 | 命中 | 判为违规："只摘录一小段"不构成豁免，改写成结论表述 |
| H6 | 把当次会话的临时文件内容整段写进长期记忆载体 | 命中 | 判为违规：临时文件内容属原始记录，不得沉淀；需要时写入结论与出处 |
| H7 | 把会议结论写成三条要求并注明材料名与日期，原始纪要仍留在原载体 | 命中且合规 | 允许写入：结论可回溯，原始记录未搬运 |

## 不应命中

| 编号 | 触发样例（场景） | 期望判定 | 期望行为 |
|---|---|---|---|
| N1 | 当次会话内直接引用会议原文做分析，不写入任何长期记忆载体 | 不命中 | 允许：原始记录可在当前任务或会话内作为工作输入 |
| N2 | 会话中临时粘贴调试日志用于定位问题，会话结束即丢弃 | 不命中 | 允许当次使用，不要求改写；只要不沉淀 |
| N3 | 写入"该接口超时阈值改为 30 秒"，并注明依据的材料名与日期 | 不命中（命中且合规） | 允许写入：结论 + 出处引用，无原始记录搬运 |
| N4 | 在会话回复中复述需求方的一句要求以确认理解，未写入任何载体 | 不命中 | 允许：不涉及长期记忆写入 |

## 执行结果

- 逐例对照规则文本判定：11/11 与期望一致（H1-H7 命中并给出应改形态，N1-N4 不命中）。
- 结论：四类载体、五类原始记录、"先粘贴再补结论"与"只摘一小段"两个边界、当次使用豁免均可逐例判定；样例本身不含任何原始记录内容。
